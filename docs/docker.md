# Docker: инструкция по использованию

В проекте три команды для работы с Docker: запуск в prod-режиме, остановка и полная очистка.

---

## Команды

| Команда                      | Назначение                                                                                                                                         |
|------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|
| **`npm run docker-compose`** | Собирает образ (при необходимости) и запускает приложение в production. Приложение доступно на **http://localhost:3000**.                          |
| **`npm run docker-down`**    | Останавливает и удаляет контейнеры, созданные docker-compose. Образ `VITE_APP_NAME` остаётся на диске.                                                  |
| **`npm run docker-clean`**   | Останавливает контейнеры, удаляет образы, собранные этим compose (`--rmi local`), и тома (`--volumes`). Следующий запуск пересоберёт образ с нуля. |

## Запуск (production)

- Собирается приложение (Vite build), статика раздаётся через nginx.
- Переменные для сборки берутся из **`.env.production`** (файл копируется в образ; новые переменные
  достаточно добавлять в `.env.production`).

```bash
npm run docker-compose
```

Приложение: **http://localhost:3000**

Остановка в терминале: `Ctrl+C`. Либо в другом терминале: `npm run docker-down`.

---

## Остановка и очистка

```bash
# Только остановить контейнеры
npm run docker-down

# Остановить и удалить образы и тома (полная очистка)
npm run docker-clean
```

После `docker-clean` следующий `npm run docker-compose` заново соберёт образ.

---

## Переменные окружения

Переменные `VITE_*` читаются из **`.env.production`** при сборке образа. Файл попадает в контекст
сборки (не исключён в `.dockerignore`). Добавляйте новые переменные в `.env.production` — в
Dockerfile ничего менять не нужно.

---

## Файлы конфигурации

| Файл                   | Назначение                                                                       |
|------------------------|----------------------------------------------------------------------------------|
| **Dockerfile**         | Сборка приложения (Node) + образ с nginx для раздачи статики.                    |
| **docker-compose.yml** | Сервис `app`: сборка и запуск на порту 3000.                                     |
| **nginx.conf**         | Конфиг nginx: SPA fallback, кэш статики, ослабленный кэш для PWA (sw, manifest). |
| **.dockerignore**      | Исключения из контекста сборки; `.env.production` не исключён.                   |

---

## Шпаргалка

```bash
npm run docker-compose   # собрать и запустить (prod, :3000)
npm run docker-down     # остановить контейнеры
npm run docker-clean    # остановить и удалить образы и тома
```
