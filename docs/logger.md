## 📊 Система логирования

Универсальный логгер с поддержкой разделов, цветовым оформлением и гибкой настройкой через `.env`.

### ⚡ Особенности

* `Error` всегда виден: ошибки показываются даже при отключенном логировании (если forceShowErrors:
  true)

* Strict Mode: в разработке логи `не дублируются` благодаря встроенной защите

* `Цветовое` кодирование: быстрая визуальная идентификация типа сообщения

* Гибкая настройка: через `.env` или программно

* Типобезопасность: полная поддержка `TypeScript`

### 🎯 Разделы логирования

| Раздел   | Цвет         | Назначение                                      |
|----------|--------------|-------------------------------------------------|
| `UI`     | 🔵 `#2196F3` | Компоненты интерфейса, пользовательские события |
| `SYSTEM` | 🟠 `#FF9800` | Системные операции, инициализация               |
| `PWA`    | 🟢 `#4CAF50` | Service Worker, кэширование, установка          |
| `API`    | 🟣 `#9C27B0` | HTTP запросы, ответы от сервера                 |
| `STORE`  | 🟤 `#FF5722` | Управление состоянием, стор                     |
| `LOGS`   | ⚫ `#795548`  | Важные события (всегда видны)                   |
| `AUTH`   | 💗 `#E91E63` | Авторизация, аутентификация                     |
| `ROUTER` | 🔷 `#00BCD4` | Навигация, маршруты                             |

### 🎨 Цветовое оформление

Каждый уровень логирования имеет свой цвет:

| Уровень | Цвет                   | Пример                                   |
|---------|------------------------|------------------------------------------|
| `ERROR` | 🔴 Красный (`#ff4444`) | `[UI] [ERROR] 15:23:45: Ошибка загрузки` |
| `WARN`  | ⚪ Серый (`#888`)       | `[API] [WARN] 15:23:46: Медленный ответ` |
| `INFO`  | ⚪ Серый (`#888`)       | `[PWA] [INFO] 15:23:47: Установлено`     |
| `DEBUG` | ⚪ Серый (`#888`)       | `[SYSTEM] [DEBUG] 15:23:48: Отладка`     |

### 🔧 Переменные окружения (.env)

| Переменная                 | Тип       | По умолчанию                 | Описание                                     |
|----------------------------|-----------|------------------------------|----------------------------------------------|
| `VITE_LOGGER_ENABLED`      | `boolean` | `true` в dev, `false` в prod | Включить/выключить логирование               |
| `VITE_LOGGER_MIN_LEVEL`    | `string`  | `debug`                      | Минимальный уровень логирования              |
| `VITE_LOGGER_ALWAYS_SHOW`  | `string`  | `LOGS`                       | Секции, которые всегда видны (через запятую) |
| `VITE_LOGGER_FORCE_ERRORS` | `boolean` | `true`                       | Принудительно показывать ошибки              |

### Примеры конфигурации:

**.env.development:**

```env
VITE_LOGGER_ENABLED=true
VITE_LOGGER_MIN_LEVEL=debug
VITE_LOGGER_ALWAYS_SHOW=LOGS,UI
VITE_LOGGER_FORCE_ERRORS=true
```

### Базовое логирование:

```typescript
// Информационное сообщение
uiLogger.info('Компонент отрисован')

// Отладка
uiLogger.debug('Детали рендера', {props: props})

// Предупреждение
pwaLogger.warn('Кэш устарел, обновление...')

// Ошибка
apiLogger.error('Ошибка запроса', error)

// Важное событие (всегда показывается)
logsLogger.info('Пользователь авторизован', {userId: 123})
```

### Продвинутые возможности

```typescript
// Замер времени выполнения
uiLogger.time('render')
// ... код
uiLogger.timeEnd('render')

// Группировка логов
uiLogger.group('Процесс инициализации')
uiLogger.info('Шаг 1')
uiLogger.info('Шаг 2')
uiLogger.groupEnd()
```
