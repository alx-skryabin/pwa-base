# 📱 PWA Project

Современное PWA-приложение на React с поддержкой темной и светлой темы, офлайн-режима, установки на
устройства и адаптивное отображение.

## 🚀 Технологии

- **Шаблон репозитория** - создание проектов и получение обновлений [[**документация**](docs/template.md)]
- **React 19** - библиотека для пользовательских интерфейсов
- **TypeScript** - типизация кода
- **Vite** - сборщик проекта
- **React Router** - маршрутизация
- **Indexed DB** - хранилище [[**документация**](docs/indexedDB.md)]
- **PWA** - прогрессивное веб-приложение
- **Docker** - Для продакшена [[**документация**](docs/docker.md)]
- **Logger** - Логирование [[**документация**](docs/logger.md)]
- **FSD** - Архитектура [[**документация**](docs/directories.md)]
- **Git Hooks** - Авто версионирование [[**документация**](docs/release.md)]
- **ESLint / Prettier / Husky** - линтинг и форматирование [[**документация**](docs/formatter.md)]
- **Vitest / React Testing Library** - тестирование [[**документация**](docs/testing.md)]
- **Storybook** - коллекция [[**документация**](docs/storybook.md)]
- **Ant Design** - библиотека компонентов

## 📋 Требования

- Node.js 18+
- npm или yarn

## 🛠 Установка

```bash
# Установить зависимости:
npm install

# Запустить в режиме разработки
npm run dev
```

## Базовые скрипты проекта

### 🚀 `npm run dev`

Запускает сервер разработки Vite с поддержкой:

- Горячей перезагрузки (HMR)
- Быстрой компиляции TypeScript

### 🏗️ `npm run build`

Выполняет два последовательных действия:

1. `tsc -b` — компиляция TypeScript с проверкой типов
2. `vite build` — сборка проекта для production

Результат сохраняется в папке `dist/`

### 👁️ `npm run preview`

Запускает локальный сервер для предпросмотра production сборки:

- Проверка собранного приложения перед деплоем
